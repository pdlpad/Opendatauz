# Источники

## Основной источник: СИАТ

Национальный комитет по статистике Республики Узбекистан, портал СИАТ: https://siat.stat.uz

Эндпоинты, которые использует проект (состав и поля проверены запросами к API, 16.10.2026, см. SPEC.md, раздел 1):

| Что | Эндпоинт | Зачем |
|---|---|---|
| Каталог показателей | `GET https://siat.stat.uz/api/sdmx/?lang=ru` | дерево разделов, 3 237 показателей, `updated_xlsx` для инкрементальной синхронизации |
| Указатель на дамп | `GET /api/sdmx/{id}/table/download/?download_format=json` | поле `file_2` — URL дампа. Поле `user` не сохраняется |
| Дамп показателя | URL из `file_2` | все значения по всем разрезам, включая районы |
| Таблица верхнего уровня | `GET /api/sdmx/{id}/table/?lang=ru` | названия на 4 языках для элементов классификаторов и территорий |
| Метаданные | `GET /api/sdmx/{id}/metadata/?lang=ru` | единица, периодичность, методология, примечание, источник, ведомство |
| Периоды | `GET /api/sdmx/{id}/years/` | список периодов |

Ограничения при обращении к СИАТ: не больше 2 запросов в секунду, ретраи с экспоненциальной задержкой, `User-Agent` с именем проекта и ссылкой на репозиторий (SPEC.md, раздел 4). Сырые ответы кэшируются локально в `.cache/`, в git не попадают.

Что в проект не попадает: ФИО, телефоны и e-mail сотрудников из метаданных и дампов (`fullname`, `phone`, `email`, `elektron_pochtasi` и т. п.), а также поле `user` указателя дампа.

## Территории: СОАТО

Код территории — `klass_id` из дампов СИАТ: `1700` — республика, 4 знака — регион, 7 знаков — район или город. Справочник строится из показателя 246 (15 + 206 кодов). Сверка с проектом [pdlpad/SOATO](https://github.com/pdlpad/SOATO): там 205 районов; Наманган-город и Наманганский район склеены в `1714401+1714212`, в СИАТ это два кода.

## Границы (этап 4)

- Регионы: из `pdlpad/SOATO`, файл `data/regions/regions.geojson`, ветка `claude/tender-einstein-1kly0y`. Исходные данные — Natural Earth (public domain).
- Районы — кандидаты, выбор по покрытию 7-значных кодов в отчёте этапа 4:
  - geoBoundaries gbOpen UZB ADM2 (OCHA ROCCA, CC BY 3.0 IGO) — 199 единиц на 2020 год;
  - OpenStreetMap, `admin_level=6` (ODbL).

Атрибуция границ выводится в подвале сайта.

## Что не источник

Значения берутся только из опубликованного СИАТ. Интерполяции, оценки и пересчёты не используются. Производные значения (нарастающий итог, удельные показатели) хранятся отдельно и помечаются.
