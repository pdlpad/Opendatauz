# Opendatauz

Открытое зеркало статистики Национального комитета по статистике Республики Узбекистан (портал СИАТ, siat.stat.uz) с привязкой к СОАТО.

> **Неофициальный проект.** Источник каждой цифры — Национальный комитет по статистике Республики Узбекистан (siat.stat.uz). Проект не связан с Нацкомстатом.

**Статус: этап 0 — каркас.** Данные ещё не загружены. План работ по этапам — в [SPEC.md](SPEC.md), правила — в [CLAUDE.md](CLAUDE.md).

## Что будет в репозитории

- 3 237 показателей СИАТ с ключом СОАТО: значения в CSV (`key,period,value`), метаданные в JSON;
- справочник территорий: республика, 14 регионов, 206 районов и городов;
- еженедельное обновление через GitHub Actions; история ревизий — в `git log`;
- статический сайт на GitHub Pages: каталог, карта, график, таблица, карточка территории, «Что изменилось».

## Структура

```
data/                 catalog.json, territories.csv, classifiers/, indicators/, geo/, manifest.json, sync_log/
tools/                Python 3.12: клиент СИАТ, синхронизация, сборка данных сайта, проверки
site/                 React + Vite + TypeScript
schema/               JSON Schema: catalog, meta, territories
tests/                pytest
.github/workflows/    ci.yml (этап 0), sync.yml (этап 3), pages.yml (этап 5)
```

Файлы данных появляются по мере этапов, см. SPEC.md, раздел 7.

## Разработка

Те же проверки, что запускает CI:

```bash
# Python 3.12
pip install -r requirements-dev.txt
pytest

# Сайт
cd site
npm ci
npm run typecheck
npm run build
```
