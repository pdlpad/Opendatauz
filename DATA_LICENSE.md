# Лицензия данных

Данные проекта — опубликованная статистика Национального комитета по статистике Республики Узбекистан (портал СИАТ, siat.stat.uz), переупакованная в CSV и JSON. Распространяются по лицензии **Creative Commons Attribution 4.0 International (CC BY 4.0)**: https://creativecommons.org/licenses/by/4.0/legalcode

Условие использования: укажите источник — «Национальный комитет по статистике Республики Узбекистан, siat.stat.uz» — и, если применимо, проект Opendatauz.

Проект неофициальный. Производные значения (например, пересчёт нарастающего итога) помечаются отдельно — их нельзя выдавать за опубликованные Нацкомстатом.

Код проекта распространяется по лицензии MIT, см. [LICENSE](LICENSE).
